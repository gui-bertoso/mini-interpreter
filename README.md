# My Programming Language - .MNY

A small experimental programming language created by **Guilherme Bertoso**, designed to compile '.mny' files into Python automatically.

## Features
- Custom syntax for control flow
- Custom print function
- Variable declarations with type hints
- Auto-generation of Python code
- Token-based compilation pipeline

## Example (.mny)
**Input:**
[File.mny](examples/input_file.mny)
**Output:**
[File.py](examples/output_file.py)

## How to run
The compiled Python code will appear in 'examples/output.py'
